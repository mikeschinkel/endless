covers: Which finished tasks claim to be done while their work has not reached the base branch.

The join nothing did: `task landed` answers from the landings table alone, so a task the table never heard of is indistinguishable from one that never existed. This asks the repository. Two sections, because they need different actions — a branch still holding commits (land it, or reset the branch) versus no landing on file at all (nothing to land; record it). Its neighbour `task unsettled` asks about a WORKTREE, not a task. Commits confined to `.endless/` do not count as the task's work.

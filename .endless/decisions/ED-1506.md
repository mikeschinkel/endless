For finite value sets that drive code branching (task types, phases, statuses, etc.), source of truth is a Go typed const. Underlying type is int; constants get explicit numeric values (no iota — reordering silently renumbers and breaks DB-persisted rows). Type provides String() returning the lowercase slug and Parse<Name>(string) for input parsing. DB has a companion values table (id, slug, label) mirroring the enum, with FK from the consuming column. Adding a value = change the enum + add a migration row. Startup integrity check hard-fails on enum/table mismatch.

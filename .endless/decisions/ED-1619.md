Settled in E-2293. Liveness has three answers: live (pane seen), dead (server reached, pane absent), unknown (server unreachable or gone). The claim/spawn guard counts unknown as live because a wrong refusal costs a retry while the inverse hands a live worktree to a second session. A display surface that SUPPRESSES rows (stewardship in session status) has the opposite cost asymmetry: a wrong suppression hides open work, a wrong show costs one line — so it counts a session only when live. The alternative, one shared 'not dead' threshold, was the plan as written; it left a session on a vanished tmux server stewarding its filings forever (E-1993/E-1995). An 'idle stewards nothing' rule was rejected as absolutist. Applies to any future view that hides or dedups rows by session.

Two alternatives were argued this session and both rejected. A filesystem probe (does the directory exist?) ties a gate over durable, shared, cross-machine content to one machine's disk and fails OPEN on its primary target: on a box with no /Users directory, a non-portable /Users path stops being detected at all. A model tier — the table-first, model-on-miss, cache-the-verdict shape the verb check already uses — would answer the ambiguity correctly and thereby reinstate the bug: asked whether /tmp is a path a model says yes, and the gate's own refusal text becomes unwritable in a lesson. The boundary with the verb check is that a registry question rewards being right, whereas content validation can be made wrong BY a right answer. Binds any future gate over ledger content, including project-configurable allowed paths.

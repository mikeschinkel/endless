Endless's tmux work happens only on the two servers Endless starts, endless-tasks and endless-console. Every command reaches them by socket path and never through the caller's own server ($TMUX). Endless never changes or manages the user's own tmux servers. This keeps ED-1607's outcome (Endless's hooks and config live only on servers it starts, never on the user's default server) and replaces its mechanism: one server, tmux -L endless, with a fallback to $TMUX outside a pane. Rejected: letting a command use $TMUX once it has confirmed that it names an Endless server, because a command can then act on the wrong one of the two (E-2196, E-2644). Mike, planning E-2572.

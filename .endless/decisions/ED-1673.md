Endless's tmux work happens only on the two servers it starts, endless-tasks and endless-console, each addressed by the socket path from the tmux settings. A command may compare $TMUX with those sockets to learn whether it is in a pane of one of them, and must not otherwise use the caller's server. Endless never changes the user's own tmux servers. Commands can be typed anywhere; a command refuses only when the server it needs is not running, when it must replace a pane on endless-tasks, or when it is a live session or project monitor outside a pane of those two servers. tmux is the multiplexer Endless integrates with today; this rule will apply to whichever servers Endless starts under any other multiplexer. Rejected: taking a server's address from $TMUX, because a command can then act on the wrong server (E-2196, E-2644). Decided by Mike reviewing E-2572 and planning E-2657.

Endless's tmux work happens only on the two servers it starts, endless-tasks and endless-console, each addressed by the socket path from the tmux settings. A command may compare $TMUX with those sockets to learn whether it is running in a pane of one of them, and must not otherwise use the caller's server. Endless never changes the user's own tmux servers. Commands can be typed anywhere; a command refuses only when the server it needs is not running or when it must replace a pane on endless-tasks. tmux is the multiplexer Endless integrates with today, not a permanent requirement: Endless expects to support others through an abstracted integration, and this rule then applies to whichever servers Endless starts. Rejected: taking a server's address from $TMUX, because a command can then act on the wrong server (E-2196, E-2644). Decided by Mike while reviewing E-2572.

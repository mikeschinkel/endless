Multiple Claude sessions can run endless-event concurrently. Rather than implementing custom timestamp-based locking, use SQLite's built-in BEGIN IMMEDIATE which acquires the write lock at transaction start, blocking other writers. The flow: BEGIN IMMEDIATE, pre-allocate ID via MAX(id)+1, write event to segment file, INSERT with explicit ID, COMMIT. If event write fails, ROLLBACK. WAL mode ensures readers aren't blocked.

The 4KB PIPE_BUF limit only guarantees atomic writes on pipes. For regular files on local filesystems, O_APPEND writes are atomic regardless of size because the kernel holds the inode lock during write(). The max event line size (1MB) is purely a sanity check against bugs (e.g., accidentally serializing binary data), not a correctness requirement. Discovered 2026-04-27 when task update --text failed with a 17KB plan file.

Between done and landed, a person is asked three things: answer a discrepancy a session filed, verify, and land. Nothing re-asks for any of them unless what the person judged has changed, measured as the branch's own work or, for a pass, main moving since it. Everything else is Endless's bookkeeping, done by the system or a session, and bookkeeping never moves a status backward. A gate that would re-ask an unchanged verdict is a bug in the gate.

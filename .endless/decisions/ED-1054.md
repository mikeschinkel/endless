Decision (E-1031): per-focus prose files (.endless/focus/EF-NNN.md) follow the same worktree-aware resolution as task plan files (E-1004 fix). Implemented as focus_cmd._focus_file_root(): if cwd is inside a git worktree of a registered project, return the worktree's checkout root; otherwise the registered project path. Files land in the worktree's branch when running from one (so they ride along with that branch's commits). Distinct from focus_cmd._project_root_for_cwd() which is naive (returns main) and used for session-companion lookup, since companion files always live in main's .endless/sessions/ regardless of which worktree the session process is in.

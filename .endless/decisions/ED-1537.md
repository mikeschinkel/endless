No X- prefix (RFC 6648: no namespacing; x-foo to foo strands everyone). IANA grammar, two separators: '/' splits family from variant (pytest/uv); '.' nests namespace in the vendor tree (vnd.newclarity.foo). Never vnd/newclarity/foo or vnd-newclarity-foo; an in-family custom type is pytest/vnd.newclarity.uv. vnd. over reverse-DNS (media-type lineage). Registry = a README plus JSON in a GitHub repo. Bare names are CURATED: a registration PR must include the contract, and PR-to-merge is the anti-spam gate. The vnd. tree is FREE-FLOATING, no registration (ownership by convention); requiring it would re-introduce removed gatekeeping. A vendor type runs only where its author's driver is loaded: free to mint, not to interoperate. Graduation = register a bare alias (reviewed PR) while the vnd. name stays valid; no forced rename. Registry status axis: registered vs vendor. Full design in the E-1789 outcome.

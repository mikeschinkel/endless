No X- prefix (RFC 6648: no namespacing, broken graduation). Steal IANA's grammar: a solidus separates family from variant, a dot nests namespace segments in the vendor (vnd) tree; no solidus or hyphen for namespacing. vnd chosen over reverse-DNS (media-type lineage). The registry is a README plus JSON in a GitHub repo, no infrastructure. Bare names are CURATED (a registration PR must include the contract; PR-to-merge is the anti-spam gate). The vnd tree is FREE-FLOATING, no registration (ownership by convention); requiring it would re-introduce removed gatekeeping. A vendor type runs only where its author's driver is loaded (free to mint, not to interoperate). Graduation = register a bare alias (deliberate reviewed PR) while the vnd name stays valid; no forced rename. Registry status axis: registered vs vendor. Full design in the E-1789 outcome.

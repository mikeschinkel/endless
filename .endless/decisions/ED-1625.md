No land process or other command removes a task's working directory (a worktree or any other form) as part of its own work; land leaves the directory in place, and the reaper removes it later, only once no session is running in it. Removing a directory a session is running in pulls the rug out from under the agent, and Endless has lost weeks to land doing exactly that. Every new land process (merge, keep-the-branch, copy-to-main) follows this rule.

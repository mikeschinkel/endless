Scope: self_dev projects only — Endless developing Endless, where a worktree sandbox and the real ledger are both reachable. Everywhere else --db is invalid: apply_db_choice refuses both values for a non-self_dev project because it has exactly one database, so no agent is ever asked for a flag that would error. Within a self_dev project an agent must name the database on every command that reaches one, whatever its cwd; a human names it only inside a worktree, where the choice is ambiguous, leaving the cwd-based gate (config.gated_worktree_root, E-1429) unchanged for humans. The risk is asymmetric: a human sees each result, while an agent runs commands in sequence with an inherited environment it did not set and reports success from an exit code, so implicit routing makes its mistakes silent. Evidence: the 2026-08-20 sandbox misrouting recorded in E-1964's analysis. Enforce at config.require_db_context / go_db_context_args, keying caller type on CLAUDECODE / internal/agentenv.

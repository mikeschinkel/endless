A command declares either one positional argument or one variadic positional argument that takes every remaining value, never two or more distinct positionals. When a command needs several values of different kinds, the extra values are flags, or the command is split into subcommands so that each leaf takes one. Mike set this on 2026-11-01 as an invariant of go-cliutil (ED-1647 in the go-cliutil project), with the reason that multiple positionals make command evolution very difficult: adding, reordering or removing a positional silently changes what every existing caller means, while flags are named and order-free. The rule is the same in every project of his; it is recorded here because Endless has no way yet to record one decision that governs several projects, and the Click CLI in src/endless/ is as bound by it as a go-cliutil command. First applied in Endless to 'endless correct <target> <operation> [KEY]' (E-2486), which had been given two positionals, target and key. See also the Gomion copy.

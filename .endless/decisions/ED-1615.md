When Endless needs to put a message into a running Claude Code session (error routing, escalation, any future nudge), it uses Claude Code's cross-session SendMessage from a short-lived claude -p sender. It never uses tmux send-keys or paste-buffer into the session's pane, which Mike rejected as unreliable and a source of usability problems. Resuming the target's transcript in a second process (claude -p --resume) is also ruled out, because the live pane never sees what that second process did. Decided in the E-2269 brainstorm; PoC results are in its outcome.

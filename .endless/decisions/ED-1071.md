endless sandbox run --clone (and equivalent on enter/create) deep-copies the user's DB to <sandbox>/endless/endless.db AND walks the projects table, copying each project's <project_root>/.endless/ tree (events, plans, sessions) to <sandbox>/projects/<project_name>/.endless/, then rewrites projects.path rows in the sandboxed DB to point at the sandboxed locations. Cost: ~200-500MB and ~500ms-2s depending on event log sizes. No --clone-prod or other variants — single flag, clear semantics. Without --clone, sandbox starts empty (fresh schema, no projects). Rationale: per-project event logs are referenced from DB rows by absolute path; without rewriting them, events written during sandbox testing flow to the real project's event log — a leak. Safety justifies the cost.

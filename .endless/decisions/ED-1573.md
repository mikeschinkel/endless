Carve-out from ED-1561, which requires an agent to name --db on every command reaching a database in a self_dev project. That is right for commands an agent CHOOSES to run against project data, and wrong for machinery it runs mechanically every turn under a contract: there the correct database is not the caller judgement, it is fixed by whatever reads the result. endless task report is the instance -- the Stop hook that consumes its checkpoint pins main unconditionally, so any other routing puts writer and reader on different databases and the gate blocks every turn as "never reported". Such a surface defaults to main when given no --db, as hook/channel/tmux already do; an explicit --db still wins. The test is not "does an agent type it" but "does something else already fix which database is correct".

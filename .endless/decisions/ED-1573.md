Carve-out from ED-1561, which requires an agent to name --db on every command reaching a database in a self_dev project. That is right for commands an agent CHOOSES to run against the ledger, and wrong for machinery it runs mechanically every turn under a contract, because there the correct database is not the caller's judgement -- it is fixed by whatever reads the result. Such a surface pins main when given no --db, as hook/channel/tmux already do; an explicit --db still wins. The test for membership is not 'does an agent type it' but 'does something else already fix which database is correct'.

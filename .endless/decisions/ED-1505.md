For any field whose value set is finite and drives code branching (task types, phases, statuses, etc.), the source of truth is a Go typed const or enum. A companion values table exists in SQLite solely for FK referential integrity and SQL-side queryability. The table mirrors the enum; the enum is never derived from the table. Adding a value = change the enum + add a migration row. Startup checks must hard-fail on enum-table mismatch.

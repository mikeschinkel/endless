Endless runs tmux -L endless, started by endless start, with a config that sources the user's tmux config and then adds Endless's layer, including the visibility hooks, so the two never collide and the hooks come back on every server start. Rejected: installing hooks into the user's default server at runtime. The user's other tmux sessions are not Endless-managed, by design; outside a pane, the tmux wrapper uses $TMUX when set and -L endless otherwise.

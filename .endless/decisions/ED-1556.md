Karpathy-style autoresearch does not bottleneck on a human approving changes, and with 70+ live sessions (ED-1550) neither can this. The user supplies ground truth in the flow of work — free-form labels and picks between paired A/B minimizations — and never reviews a prompt diff. The judge predicts the user's reaction BEFORE seeing it; rolling prediction-vs-outcome agreement says whether it still predicts which output the user prefers. Low agreement must NOT halt the loop: a loop that silently stops improving while the user keeps labelling lets them believe their input is doing something when it is not. Losing the user's preferences is answered by asking more often — raise the A/B sample rate — and by saying so in-band.

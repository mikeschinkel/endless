A precondition an agent evaluates is one it can decide has been met: on 2026-08-25 two sessions ten minutes apart removed worktrees, neither overriding the rule, both concluding conversation had satisfied it. E-2073 replaces the asking with a PreToolUse refusal covering every route (drop, reap, git worktree remove, rm -r), with no bypass flag, since a session that talks itself into 'I was asked' will talk itself into 'this is what the bypass is for'. This reverses the half of E-1947 that assigned removal to the spawning session — the hook fires on ANY Claude session's Bash tool, so the person running the session removes worktrees in their own shell and the reaper handles stale ones.

When a CLI command has an implicit default that hides certain results (e.g., task list hiding terminal statuses unless --all is passed), an explicit filter flag for that same dimension (e.g., --status assumed) MUST override the implicit default. Rationale: a user passing --status X is unambiguously asking for X; requiring them to also pass --all is surprising and forces redundant flags. Apply to all current and future filter flags. First instance: E-959 fixed task list and task search.

Both flags write to the same 'outcome' TEXT column on tasks. Different flag names per verb (--reason on decline, --outcome on confirm/assume/replace/update) honor the cowpath agents instinctively follow when typing each verb in context. Strict consistency (--outcome everywhere) was rejected because agents reach for --reason on decline first, wasting tokens learning the rule. This sets a precedent for future terminal-status verbs: prefer the agent-natural flag name even at the cost of one column-to-flag mapping per verb.

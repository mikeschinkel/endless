worktree check runs the same checks as endless doctor's worktree scope and produces the same output, while keeping its handoff contract: silent when clean, same exit code, failing on errors only. Adding a worktree-scope check to doctor adds it to the handoff gate automatically. Chosen over keeping worktree check separate with a hand-picked check set, which would drift from doctor, and because worktree check's purpose is opaque to users and nobody would think to look for it.

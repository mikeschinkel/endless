Endless auto-initiates a spawn (still a first-class interactive session) only for tasks clearing ALL FOUR conditions, computed at spawn-decision time: status = ready, complexity below threshold, risk below threshold, and phase in (now, urgent). Complexity and risk answer 'safe to run unattended'; status answers 'authorized' (ready means human-approved, the actual authorization for unattended work); phase answers 'wanted now' — without it a simple low-risk task parked at 'later' would run itself, and 'maybe' is worse since it means may-or-may-not-be-done-at-all, so auto-completing one decides a question the user reserved. Ratings are agent-proposed at submit and user-ratified at approve; ED-1539 covers the two-axis shape. Amended 2026-08-20 under E-1991 to add status and phase, which were implicit in E-1814's title but never stated as eligibility criteria.

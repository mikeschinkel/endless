Modifies E-1056. The auto-commit list at worktree land changes: .endless/verbs.json is added; .endless/config.json is removed. Rationale: verbs.json mutations are ambient (agent-driven, frequent) and benefit from automatic bundling into a separable commit at land; config.json edits are rare, deliberate acts whose attribution and intent the user wants to control. The worktree-land flow normalizes/dedups verbs.json against main's verbs.json before committing, so two worktrees that independently added the same verb produce no merge conflict (set-union on value key, in Go code). Rejected the alternative of a .gitattributes JSON merge driver as a deployment burden; endless wants to manage everything possible inside its own Go code rather than git configuration.

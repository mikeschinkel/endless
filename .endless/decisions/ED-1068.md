When orphaned sandboxes exist (ephemerals whose creator_pid is dead), 'endless' prints a one-line warning at startup with explicit disable instructions: 'warning: 3 orphaned sandboxes (run "endless sandbox prune" to clean, or "endless config set sandbox.startup_warning false" to silence).' Default ON. Rationale: silent options are invisible options — users who'd benefit from knowing about orphans never discover the feature exists. Visibility (and instructions to disable) > temporary annoyance. Pattern generalizable to other actionable warnings.

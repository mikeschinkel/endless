pytest 'sandbox' fixture yields a Sandbox object exposing four members: sb.run(cmd) — invoke endless commands; sb.db — sqlite3 connection to sandboxed DB for direct SELECT in test assertions; sb.env — dict of env vars (XDG_CONFIG_HOME, ENDLESS_SANDBOX, PATH) to pass to further subprocesses; sb.path — sandbox dir for inspecting files. Wrapped as a context manager so cleanup is automatic via pytest's tmp_path lifecycle. Rationale: object+methods is the Pythonic choice; far cleaner than a collection of disjointed helpers like _seed_project_at_cwd that E-787 had to invent ad-hoc. Mike confirmed preference for objects over inconsistently-named functions in Python.

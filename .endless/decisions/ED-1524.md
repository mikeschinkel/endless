For a research task executed via Claude Web (claude.ai Research), the task's text field holds the ready-to-paste research prompt. This is 'the request' under the research-task field model (text = request, outcome = deliverable): the prompt is pasted into Claude Web, and the returned cited report plus any synthesis becomes the task outcome. Plan text must be the actionable artifact (the prompt), not narration that merely restates the intent to run research. Worked example: E-1724.

ENDLESS_VERIFY_RUN gated a verify suite's direct run on the PRESENCE of an environment variable. Nothing read its value, so one export satisfied it — and because it looked like enforcement, no enforcement was built behind it: the own-task-only rule lived solely in the runner, which a direct run never reaches. A check that can be satisfied by lying is not a check, and is worse than no check, because the green it produces reads as proof. Guards therefore key on conditions the environment actually exhibits — the running file's own path, the reachability of a real config, a live process holding cwd — each satisfiable only by the caller genuinely being in the state claimed. This binds any future gate in this system, not only verify suites, and it is the standard against which the E-1916 hook arms should be judged.

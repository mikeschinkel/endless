Three new types for work that writes code that is not merged into the project. An experiment tries an approach on the project's own code in a project worktree on an experiment branch; it is never merged, and completion requires keep (the branch is preserved) or discard. A prototype is a self-contained proof of concept built in an empty repo; completion requires keep (copied to .endless/prototypes/e-NNNN/ on main) or discard. A tool is a self-contained utility built in an empty repo with its own test suite, which must pass before land; it follows the verification lane and lands by copy to .endless/tools/e-NNNN/. Prototypes and tools carry README metadata as YAML front matter inside an HTML comment. 'Spike' is dropped as a name.

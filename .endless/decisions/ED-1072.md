endless sandbox enter <name> forks a subshell with the sandbox's env vars set (XDG_CONFIG_HOME, ENDLESS_SANDBOX, PATH). User runs commands in the subshell; 'exit' returns to the parent shell with original env restored. Alternative — modifying current shell's env via eval/source — was rejected: subshell is more robust (exit always works cleanly), avoids the trap of leaving stale env vars when something goes wrong. Speed cost (a few ms to spawn subshell) is negligible. Confirmed during E-995 planning conversation: 'Robustness > a few milliseconds faster.'

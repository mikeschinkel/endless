Defines "rank" for the session-task relations of ED-1497 (claimed, queued, surfaced, revisited, referenced, and bound from E-2291). Rank is a total order over the relations, defined by Relation.Rank() in internal/sessiontaskrelation. It decides two things, and nothing else. (1) Upgrade: when a task enters a session's list a second way, the row keeps the higher-ranked relation and never downgrades, as upsertSessionTask does. (2) Display: endless session status orders rows that are otherwise equally actionable by rank, so decided work sits above incidental work. Rank is not persisted, so it can be reordered without a data migration; the relation ids stored in session_tasks.relation_id never change. An unknown relation ranks last.

When a guard had to reach 138 worktrees that predated it, committing the change into each branch's copy was measured against rebasing them. The edit turns a currently-clean rebase into a conflicted one and leaves suites double-guarded, because main has already changed the same files at their new paths; rebasing arrives clean and delivers the final state in one move. More broadly, writing into another session's branch to distribute a shared change puts work there that its owner did not author and must later reconcile. The sweep that does the rebasing must skip any worktree in use and fail closed when it cannot tell, because rebasing under a live session changes every file beneath a process that has already read them — an agent then editing from what it read silently reverts what arrived.

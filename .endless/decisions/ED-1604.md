An Endless mod loaded in each Claude session delivers Endless's messages and notices to it, with session notices as the source of truth. Because the mod is Endless's own code running inside the session, it delivers without a model turn. When mods are off or unavailable, delivery falls back to passive notices on the next prompt plus the session status/monitor reveal. Source: docs/brief-2028-10-02-claude-code-mods-brief.md.

An Endless mod loaded in each Claude session delivers Endless's messages and notices to it, with session notices as the source of truth. The mod is Endless's own code, so it delivers without a model turn (which SendMessage needs), and its session.send/session.receive use Claude Code's own cross-session transport, so mods subsume SendMessage for Endless. MCP is not used for messaging: it cannot deliver unprompted. The CLI and background jobs never write Claude Code's internal socket, which is undocumented and too fragile. With mods off or unavailable, delivery falls back to passive notices on the next prompt plus the session status/monitor reveal.

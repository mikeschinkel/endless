The endless guide's sections are written for the AI agent, so context/token load is minimized. Commands intended only for human users (interactive tmux navigation, live-watch views, etc.) are documented in a separate appendix (docs/guide/appendix-a.md, 'User-focused commands') and referenced from agent-facing sections with a single minimal pointer — never inlined. The appendix may appear in the section list, but naming it an 'appendix' signals agents to deprioritize it; they pull it into context only to inform a user. No guide/guide_map code change is needed.

Agent handoffs and end-of-session status reports are generated by feeding a validated XML payload to 'endless task report <id> --xml', which returns the complete message the agent relays verbatim. Ceremony (negative-confirmation, inventory-of-the-silence) is made UNREPRESENTABLE by construction rather than detected after the fact: computable facts (git/worktree/external) are produced by the tool (handoff-status, E-1758) so the agent never types them; the remaining fields carry validated values (none = silence) with out-of-set values rejected; the sole free-text escape hatch (non-computable anomalies) is guarded by a scoped, tunable Haiku check. Phrase/deny-list matching was tried and rejected (too many false positives/negatives); determinism comes from removing the freeform surface. Interception is a CLI command (not a hook) because the work can be done with one; a reminder on terminal status-set nudges toward it, and a user 'FULL STATUS' keyword opts back into unconstrained detail on demand.

Stored paths are written home-relative — a tilde prefix — and expanded when used. Chosen for legibility: absolute paths make ad-hoc SQL against the ledger painful, and 'endless sql' is a supported surface, not a debugging back door. Mike weighed the alternative explicitly and preferred being wrong this way over keeping absolute and never testing the assumption. Paths outside $HOME stay absolute, so the column is mixed by design. This does not weaken E-2002's invariant, it re-points it: there is still exactly one canonical spelling, symlinks are still resolved before relativizing, and normalization still happens at the boundaries — the DB read and the harness-supplied cwd — never per comparison. Two forms now exist and must never be confused: the STORED form (home-relative; what comparisons and writes use) and the RESOLVED form (absolute; what touches the filesystem). Accessors must make which one you hold obvious at the call site.

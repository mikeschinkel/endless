Two languages compare project paths: the Python CLI writes projects.path, the Go hook reads it on every Claude event. Divergence is silent and total — the hook misses the registered row and auto-registers a duplicate the session binds to. So the stored form is fixed by decision: absolute, every symlink component resolved, non-strict (a not-yet-created directory still gets its existing prefix resolved — what pathlib.resolve does and filepath.EvalSymlinks alone does not). Two implementations that must not drift: monitor.NormalizeProjectPath/MatchProjectPath and endless.project_path. The corollary is what makes it maintainable: normalize at the BOUNDARIES — the DB read, and the cwd the harness supplies, done once at hook entry — not at each comparison, so a later contributor cannot get it wrong by omission. Tilde expansion is input tolerance inside the helper, NOT part of the stored form: nothing writes a ~ into that column.

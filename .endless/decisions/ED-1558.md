The E-1815 seed hypothesized one dedicated window hosting both selector and monitor; the brainstorm split them, because conflating them produces a daemon in disguise. The trigger is one more registered job on the E-698 fire-once runner, so its rate is the job cadence field rather than a timer anyone builds. The window is justified purely by display — the attention dashboard (E-1976) needs somewhere to live — and needs no session row or new session kind. The consequence, that auto-spawn runs only while the window is open, is accepted as a feature: closing it is a kill switch needing no code and no config, and the user is by construction present-ish when work is initiated. Surviving a closed window is exactly where a daemon gets chosen; keeping it out of v1 defers that as an explicit later decision rather than inheriting it silently.

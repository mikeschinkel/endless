Three steps, ending where it started: a fixed set (CUT/BLOAT/WRONG/GOOD), then any freeform token, then none. A sigil the user types sits in the prompt, so the agent sees it and comments on it — at length, which is exactly what the minimizer exists to stop. Measured on 2026-08-16: 31 uses, 3 recognised, and the ones that worked invited a reply about the criticism. So critique moves out of band to an endless feedback command, run in a pane the agent never sees, silent on success and loud on rejection. Nothing takes the sigils' place in band: a model can read sentiment from the user's ordinary words, so a special syntax buys nothing while costing a vocabulary nobody can recall mid-complaint.

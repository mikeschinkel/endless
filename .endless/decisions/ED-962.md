Implementation approach decision for the policy decision (sibling). Schema-level NOT NULL on the existing nullable description column would require a SQLite table rebuild (per the schema comment, prior table-rebuild migrations caused catastrophic data loss in this repo). Risk-reward poor. Better to enforce at the write boundary: endless task add, endless decision add, endless task update. CLI can also be smarter than the schema, e.g., auto-derive description from the first non-blank line of --text when --text is provided and --description is not. Display-side fallback (show text excerpt when description is NULL) covers any pre-policy NULL rows that survive backfill.

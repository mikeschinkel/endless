When 'endless task update' changes one or more fields, the per-item output line should display the new value for each field, not just the field name. Rationale: a user (or agent) reading the output wants to verify what the new state actually is without a follow-up 'task detail' call; field names alone confirm only that something changed. Format: '• Updated E-###: status=ready, tier=2'. For long blobs (text, prompt) show a compact marker like '<set>' or '<cleared>' rather than dumping the body. Cleared values (None) render as 'cleared' or similar sentinel. Applies to all fields the update command accepts.

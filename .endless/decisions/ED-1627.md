Every tmux socket directory Endless creates or chooses (the default, the verify runner's, the Go test helper's, any per-sandbox one) sits directly under /tmp with a short name, never under HOME, a worktree or sandbox, or the OS temp dir: a Unix socket path is capped at ~104 bytes, which those can exceed, and a socket is runtime state, not config. Designs that need a socket directory apply this rather than reopening the path-length question.

Every tmux socket directory Endless creates or chooses (the default, the verify runner's, the Go test helper's, any per-sandbox one) sits directly under /tmp with a short name, never under HOME, a worktree or sandbox, or the OS temp dir. A Unix socket path is capped by sun_path: 104 bytes on macOS, 108 on Linux and on WSL. HOME, worktree and sandbox paths can exceed that on any of them; the OS temp dir can on macOS, where it is a long per-user path under /var/folders. A socket is also runtime state, not config. The rule applies on macOS, Linux and WSL; native Windows is not supported, since tmux does not run there. Designs that need a socket directory apply this rather than reopening the path-length question.

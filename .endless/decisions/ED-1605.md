Owner: the Endless session that claimed the task. A task has one owner, and it never changes, because a claim is write-once. The owner's current Claude session is the Claude session running for that Endless session now; it changes on /clear or resume, and is always written in full, never shortened to 'owner'. Steward: the session whose session monitor shows the task (after duplicate resolution, normally the session that filed it), so the task gets spawned or rejected; it stays the steward after spawn, with the row dimmed. Landing is done from the owner's side, today by the user in a tmux sibling pane of the owner's window, never by the steward or the spawning session. Worktree lock holder: the process holding a worktree's worktree.lock. Approving, verifying, confirming and closing are the user's acts. Endless uses 'own' for nothing else.

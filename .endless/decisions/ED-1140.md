Reverses E-1112. Project-config writes (both .endless/config.json and .endless/verbs.json) resolve to the nearest .endless/ directory walking up from cwd, not anchored to the main checkout. From a worktree, writes go to that worktree's files; from main, writes go to main's. Rationale: (a) cannot test config.json changes safely if they immediately mutate main's tracked file, (b) config.json edits in main should reflect deliberate user action, not ambient endless CLI activity, and (c) with rapid worktree-merge cadence, riding verbs into main via the worktree-land flow is operationally fine. Implementation reverts the git-common-dir lookup added in E-1111.

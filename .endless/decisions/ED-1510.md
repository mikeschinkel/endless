Maybe = uncommitted; parent-child = scope binding. A parent with maybe-phase children creates phantom scope — it appears done while uncommitted commitments linger inside, and breaks the cleanness of epic auto-derivation (E-1541) which can't safely treat maybe children as part of the parent's outcome. Therefore: phase=maybe and parent_id IS NOT NULL must not coexist on the same row. Enforcement at the write path (task add / task update). The relates_to link type preserves conceptual adjacency without violating the invariant; see E-1616 for the validator + survey.

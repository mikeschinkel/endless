Touch is the user's command for putting a task on a session's status list. A touched task stays on that session's board even while another present session stewards it; the duplicate mark still warns of the overlap. There is no separate pin concept: session unhide --task on a task that is not hidden refuses and names session touch. A touch does not make the session the task's steward: the user may touch a task only to see it. E-2414 retires pins; E-2291 renamed the command to session touch.

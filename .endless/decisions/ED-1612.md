Epic and group rows show container states instead of a task's actions, so a container is never read as a do-task to plan or verify. Epic: unplanned (objective or strategy missing, the plan pencil), submitted (has both, no child started), underway (a child has started), complete (all children terminal). Group: submitted, underway, complete. These are display names computed from the container's own rows and its children's states, not new statuses; on an epic, unplanned means the epic itself lacks an objective or strategy, never that some child lacks a plan. Each state gets its own glyph, distinct from the do-task glyphs. project status and the session monitor show four sections, urgent, epics, groups, other, with epics before groups. This replaces the epic status rules in E-1537's plan, which stays as history.

Branch refs are redundant once merged: every commit stays reachable via the merge commit on main, the branch name is preserved in the merge commit message ('Merge branch task/NNN-...'), and 'git branch -d' refuses unmerged branches by default. Recovery is 'git branch <name> <merge-commit>^2' if ever needed. The chaos cost of 20+ stale refs in 'git branch' compounds across 40+ active projects and obscures actually-active work. Policy: after a task/* branch lands on main, delete the local ref. Worktrees are dropped per existing convention; the branch deletion is the parallel step for the ref.

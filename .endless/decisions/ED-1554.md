A worktree's sandbox lives at `<worktree>/.endless/sandbox/`, gitignored, with a lifetime exactly equal to the worktree's — not under the XDG cache root. In-tree because the sandbox holds files a task is exercised against (throwaway DB, fixture spreadsheet, OpenAPI doc) that get opened and edited in the IDE already holding the worktree; the cache root was also wrong on XDG's own terms, which define cache as deletable without loss. Worktree-lifetime because it makes orphans structurally impossible rather than managed: 126 sandboxes, 102 MB, roughly two dozen already orphaned when this was decided. Anything that must outlive the worktree does not belong in a sandbox — commit it. Consequences: provisioning becomes universal, `self_dev` is retained only for endless's own DB routing, resolution becomes composition with no new env var, and the `XDG_CONFIG_HOME` injection and `sandbox bind` are deleted.

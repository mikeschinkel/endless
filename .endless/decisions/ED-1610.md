An initiative epic carries two task_content rows, never a plan: objective, what is true when the epic is done, which stays fixed (if it changes, it is a different epic); and strategy, the approach, which is expected to change as children uncover things. Distinct names make an agent behave differently, so the epic/todo distinction does not depend on the agent noticing the type. Both are required to claim or spawn an epic, and only there: task add accepts an epic without them, as it accepts a todo without a plan (filing stays cheap). An epic missing either shows as unplanned. Existing epic plans move into objective and strategy case by case; a plan that fits neither stays as a legacy plan row.

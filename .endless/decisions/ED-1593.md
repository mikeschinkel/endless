Where a command has no agent rendering, --format agent is refused by name with the rendering that works named first (ED-1584), rather than advertising a value the command cannot honour or quietly returning the human view. Rejected: silent fallback, which would hand an agent session status's glyph-encoded ownership signal as if it were agent-facing, the failure E-2143 exists to end; and advertising the full set everywhere, honest at the call and dishonest in --help. click.Choice cannot separate the advertised set from the accepted set, so a custom parameter type is the cost of the rule. Generalizes beyond output formats: when a capability arrives surface by surface, a place that lacks it refuses by name and says what to use instead.

endless sandbox prune scope is orphaned ephemerals only. No --all flag — if user wants everything gone, 'rm -rf ~/.cache/endless/sandboxes/' is one command, not a CLI we should encourage. --older-than DURATION accepted, with 24h minimum enforced: any value below errors with 'minimum --older-than is 24h'. Rationale: a sandbox <24h old might still be 'in use' mentally even if process died (debugging, partial test runs). YAGNI on --all — the destructive sledgehammer is already available via shell. prune always outputs scope being addressed before acting, e.g.: 'Pruning 3 orphaned ephemeral sandboxes older than 24h: ...'.

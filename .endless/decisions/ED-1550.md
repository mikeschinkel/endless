A project whose agents file more tasks than they close has no completion date. Arithmetic, not preference: while the file-to-close ratio exceeds 1.0 the backlog diverges, and working faster raises both sides. Measured here over sixty days, 391 filed against 264 closed (~1.5); lifetime ~1.9. Agents cause this, so agents carry the rules. (1) Filing is the exception; the default response to a finding is to tell the user in chat. Noticing something true does not earn a task. (2) Fold before filing: a finding supporting existing work is evidence in that task's analysis, and several symptoms of one cause are one task. (3) Search for the task already owning the area first. (4) A request to file is not unlimited; say which items are better recorded as evidence, file the rest. (5) Reporting never means filing. Any mechanism surfacing friction or discovery must surface it in conversation, never auto-file. (6) Closing is work: obsolete, decline, and park are the only fast lever on the ratio.

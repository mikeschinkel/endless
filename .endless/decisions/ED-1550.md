A project whose agents file more tasks than they close has no completion date. Arithmetic, not preference: while the file-to-close ratio exceeds 1.0 the backlog diverges. Measured here over sixty days, 391 filed against 264 closed (~1.5). Agents cause this, so agents carry the rules. (1) Filing is the exception; the default response to a finding is to tell the user in chat. Noticing something true does not earn a task. (2) Fold a finding into an OPEN task as evidence, but NEVER reopen shipped work to extend it: a bugfix or enhancement to a landed task is a NEW task even on the same subject and feature, because reopening forces the user to re-read a whole plan to find the new part. Reopen only when what shipped is wrong. (3) Several symptoms of one cause are one task; file the cause. (4) Search the area for an owning task first. (5) A request to file is not unlimited. (6) Reporting never means filing. (7) Closing is work: obsolete, decline and park are the only fast lever.

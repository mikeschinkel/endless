report_prompts.py ships "you are deleting, not rewriting" (l.123-125) and "YOUR OBJECTIVE IS NOT TO MAKE IT SHORT" (l.60). Neither was the user's intent; both were written by an agent in a prior session and later cited back as authoritative. The corpus corroborates the defect: keep-ratio is 0.62 at 1-2k but 0.86 at 2k+, because on long drafts the padding is diffuse and unreachable without rewriting. The objective is to remove what the user can already see in session status, what is already in the task plan or analysis, jargon, puffery, and the agent showing its work. Deduplication against what the user already has is the novel half. Ships as a change, not as an A/B variant — it is a build defect, not a hypothesis.

On worktree creation (E-986's post-worktree-create hook, covering both claim and spawn), endless's hook COPIES the main checkout's prebuilt bin/endless-go into the worktree and repoints the Claude hook at it; it does NOT run 'just build'. Rationale: a freshly created worktree is identical to main (no candidate code yet), so building only slowly reproduces the binary main already has — copying is the identical result instantly. The agent rebuilds with 'just build' only once its branch diverges in Go. Backstop: a non-blocking stderr warning fires when a hook runs a foreign build inside a self_dev worktree (never a refuse, which would block every tool call). Overturns the earlier build-at-provision approach. 'just' stays confined to the project dev-wrapper hook; shipped Go/Python never shells to it (PRODUCT).

Sandbox feature is composed of three optional layers: (#1) env-var foundation — XDG_CONFIG_HOME redirection — Go honors natively, Python gained support via E-1020. Always present. (#2) Opt-in deep clone (--clone flag) — copies user's DB plus per-project state with paths rewritten. For migration, integration, and sanity testing. (#3) Opt-in OS-level guard via Go 1.24's os.Root — kernel-level write barrier on prod paths. For paranoid runs. Layers compose; none replaces another. Rationale: each layer addresses a distinct concern (isolation mechanism, starting state, leak protection); collapsing them would either over-spec the cheap default or make the robust mode mandatory.

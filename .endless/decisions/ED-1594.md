SQLite has DROP TABLE IF EXISTS but no DROP COLUMN IF EXISTS, so E-2142's two column drops could not be written safely in SQL. Replay-safety is required rather than nice: schema.sql is still exec'd directly to build a database from the declared shape, so a step routinely meets a database already holding what it intends to produce, and TestMigrate_LeavesAPreVersioningDatabaseIntact asserts it. 00002 met the additive half with CREATE VIEW IF NOT EXISTS; a Go step meets the destructive half. The argued alternative was to relax the invariant instead, rebuilding that test's fixture from the baseline — smaller, and touches no production code. Rejected: the constraint binds every path that builds from the declared form, not just that fixture, and SQLite's DDL gaps will recur. This is not the baseline's blanket idempotence, which no-ops wholesale so a run and a skip are indistinguishable; a Go step probes one named object and skips only that.

Plans are itemized: one-line, independently checkable deliverable or exclusion items, numbered P<n>, approved as a baseline. After implementing and before any verify, the agent records one verdict per active item; every discrepancy (not kept, not done, blocked, done differently, or unapproved grown work) becomes a kind-tagged question. One deterministic gate, run on setting unverified or assumed and inside task verify, passes only when the task has a deliverable item, the items match the approved baseline, the reconciliation's code fingerprint and plan digest are current, and every discrepancy is settled or carries an earlier answer the agent re-checked against the whole task. Terms and mechanics: endless guide tasks, Plan items and Reconciling before a verify.

Plans are itemized: one-line, independently checkable deliverable or exclusion items, numbered P<n>, approved as a baseline before the task is spawned; every todo and bugfix must have them. After implementing and before setting unverified, the agent records one verdict per active item; every discrepancy (not kept, not done, blocked, done differently, or unapproved grown work) becomes a kind-tagged question. One deterministic gate, run on setting unverified or assumed on any task with plan items and inside task verify, passes only when the task has a deliverable item, the items match the approved baseline, the reconciliation's code fingerprint and plan digest are current, and every discrepancy is settled or carries an earlier answer the agent re-checked against the whole task.

Self_dev only (ED-1571). Replaces the E-998 pin, under which the candidate binary was the only thing that ran, so when it broke nothing was alive to report it. Whether main's binary spawns the worktree's is an explicit per-task declaration rather than inferred from the branch diff, because the use-cases cannot be enumerated in advance but whoever is doing a task knows. The default is main, deliberately opt-in, justified by asymmetric error cost: the wrong worktree choice has twice meant machine-wide breakage while the wrong main choice only means hook code ships untested. Declared by the session or the user at any time via a command, announced in the session's opening message, stored worktree-locally so it is readable before monitor.DB() connects and adds no column that every non-self-dev project would leave NULL. Compatibility semantics remain ED-1570's exact version agreement.

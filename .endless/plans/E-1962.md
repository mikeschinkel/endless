# E-1962 — implementation record

## The empirical finding that decided the design

Claude Code Desktop told Mike `CLAUDE_CODE_ENTRYPOINT` "does not exist". It does.
Both surfaces were dumped on 2026-08-13:

| var | terminal (CC 2.1.222) | Desktop app |
|---|---|---|
| `CLAUDE_CODE_ENTRYPOINT` | `cli` | *absent* |
| `CLAUDECODE` | `1` | *absent* |
| `CLAUDE_AGENT_SDK_VERSION` | *absent* | `0.3.222` |
| `__CFBundleIdentifier` | `com.apple.Terminal` | `com.anthropic.claudefordesktop` |

Desktop hosts the agent through the **Agent SDK**, not the CLI, so none of the
CLI's own variables reach a hook subprocess there. That gap is the discriminator.

## What shipped

`internal/hookcmd/surface.go` — new. `terminalSurface()` returns
`os.Getenv("CLAUDE_CODE_ENTRYPOINT") == "cli"`.

**Allow-list, not deny-list.** A deny-list must name every surface that exists,
and the cost of missing one is that a brand-new Claude Code host silently starts
enforcing a contract nobody chose for it. The allow-list's failure direction is
the opposite — an unrecognized surface lands ungated, which is where everything
except the terminal is meant to be.

**One variable only.** `CLAUDE_AGENT_SDK_VERSION` was rejected as a second
signal: it says "an SDK hosts this agent," not "this is not a terminal," and a
terminal-launched SDK/background session could plausibly carry it. Treating it as
disqualifying would switch the channel off for terminal sessions that should
have it.

`internal/hookcmd/claude.go` — `reportChannelOn` gained the check. Placement is
the whole point: that one function feeds the SessionStart rule, the PostToolUse
reinforcement, AND the Stop gate, so E-1953's told-iff-gated invariant holds
automatically. Gating a single call site would have satisfied "Desktop isn't
blocked" while still telling Desktop to report.

Surface and `report_gate` are **independent vetoes** — the product's decision and
the project's, both must say yes. Never an override: a terminal session in a
`"report_gate": false` project (Endless's own checkout) stays off.

`internal/hookcmd/claim_handoff.go` — the handoff's `report_gate` var is now
`terminalSurface() && ReportGateEnabledForCwd(...)`. This renders in the
*claiming session's own hook*, so the environment read is that session's.

## Deliberately NOT changed

`src/endless/task_cmd.py:_handoff_report_gate()` (the **spawn** handoff).
`endless task spawn` opens a tmux window, so the session it describes is a
terminal by construction whatever surface ran the command. Gating it on the
caller's environment would strip the contract from terminal sessions spawned
from Desktop. `tests/tasks/e-1962-verify.sh` asserts `CLAUDE_CODE_ENTRYPOINT`
never appears in `task_cmd.py` so this stays deliberate rather than drifting.

## Regression caught and fixed

`tests/tasks/e-1953-verify.sh` drives the real hook from a **bare shell**
(`esu && ./tests/tasks/...`), where `CLAUDE_CODE_ENTRYPOINT` is absent — 12 of
its assertions started failing. The script impersonates a terminal Claude
session, so it now `export`s the environment it is impersonating. Verified: 69/69
from a bare shell.

## Verification

`./tests/tasks/e-1962-verify.sh` — 17 checks, all passing. Both surfaces are
simulated by environment alone (`env CLAUDE_CODE_ENTRYPOINT=cli` vs `env -u`),
which is not a stub of Desktop but a reproduction of the exact condition.

- Part 0: build, vet, `go test ./internal/hookcmd/...` (fail-fast).
- Part 1: all three consumers, real hook binary → sandbox DB. Terminal injects
  the rule / blocks an unreported reply / fires the reinforcement; Desktop is
  silent on every one.
- Part 2: terminal + `report_gate:false` → still off (veto, not override).
- Part 3: claim handoff gated; Python spawn handoff provably left alone.
- Part 4: E-1953's suite re-run end-to-end from a bare shell.

Project-wide: `go build ./...`, `go vet ./...`, `go test ./...` clean;
`just test` 1357 passed.

## Found along the way — filed as E-1965

Two verify suites fail on **baseline main**, unrelated to this change:
`e-1901-verify.sh` (17 failures, asserts contracts E-1953 retired) and
`e-1822-verify.sh` (1 failure, fixture payload never gained E-1953's
`report_gate` var). Shared root cause: E-1953's rewrite left them stale.

## Open question for later

The terminal-only rule is hardcoded, matching Mike's "currently" framing — a
product policy that may widen, not a per-project knob. If a second consumer ever
wants a different set, promote it to a `report_gate_surfaces` config key rather
than growing conditionals in `terminalSurface`.

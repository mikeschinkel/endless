Existing populated databases must be BASELINED, not replayed: a real ledger already carries most of these changes, so the conversion has to mark them applied rather than re-run them. Note that _schema_version is a set of applied change-file basenames, not an ordered version, so baselining has to map that set onto goose's version sequence.

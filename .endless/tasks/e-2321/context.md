Mike raised this while working on reconciling plans against finished work, which added open-question tracking, a spawn gate on unanswered questions, and board icons for unanswered questions. His ideas: (1) agent-led, where the agent walks the user through the questions, vs. command-driven, where the user answers from the CLI; (2) marks such as 'need more info' and 'need pros and cons of options'; (3) pros and cons gathered for every question in advance, as a configurable option; (4) a command that messages the task's session (a Mod) to process the answers. The trade-off he named: convenience vs. token efficiency.

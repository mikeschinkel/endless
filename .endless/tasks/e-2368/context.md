On 2026-10-15 an agent (the recovery session, Claude session 9c93bea6) ran endless start after the task-session server crashed. A new tmux server copies the environment of the process that starts it into its global environment, so every pane it created inherited the agent's CLAUDECODE=1, CLAUDE_CODE_SESSION_ID, CLAUDE_CODE_CHILD_SESSION, CLAUDE_CODE_MESSAGING_SOCKET/TOKEN, CLAUDE_PID, CLAUDE_EFFORT and related variables: the user's shell panes, the 44 session monitor panes, and the 45 resumed Claude processes. Endless reads these variables (internal/agentenv, src/endless/agent_env.py, hookcmd, monitor, task_cmd and others) to tell an agent from the user, so commands the user typed in sibling panes were treated as the agent's. Repaired by hand: set-environment -gu on the server, respawn-pane on the monitors, unset in idle shells. Recovery is exactly when an agent is likely to run endless start. PRODUCT: affects any user who lets an agent start or restart Endless's tmux servers.

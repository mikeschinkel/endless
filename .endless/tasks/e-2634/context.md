From the E-2632 brainstorm (ED-1664). Landing E-2529 printed a yellow "post-land items still open" list ending "Do them on the landed, installed result". Mike, who ran the land, could not tell that the items were the claiming session's, and the message read as a failure. Post-land items hold only a statement of what will be true, so no reader can tell who does each item or what to run. The land message and the post-land guide also assume Endless's own self-dev setup: migrations and a locally installed build.

What Mike settled:
- **Owners.** Every post-land item names cli (Endless runs it), agent (the claiming session) or user. Owner user also covers work Mike prefers to do himself; a separate "dangerous" flag is deferred.
- **Actions.** Each item carries runnable commands alongside its statement. Commands look up values such as SHAs or run IDs when they run instead of holding them.
- **Checks.** A cli item also requires a check command that tests its statement is true. Endless refuses a cli item without one, so an agent cannot forget the check (exit 0 of the action alone is not enough).
- **Order.** Items run in plan order; running independent items in parallel can wait until it is a real concern. Land runs the leading cli items and stops at a failure or at the first agent or user item. Recording that item, by `plan done` or reconcile, runs the cli items after it, up to the next non-cli item. A failed cli item stops the sequence, leaves the task `landed`, and the output names the failed command and how to rerun it (`task plan run`).
- **`task plan done E-<id> P<n>`.** A user records one of their own items with this. Reconcile's verdict file is an agent's tool.
- **Land report.** It says first that the land succeeded, then lists only the user's own items with their commands. It drops "installed".
- **Handoff.** Agent-owned items are sent as a prompt into the claiming session's tmux pane. Mike is rarely talking with a session when he lands it. When the session isn't running, the land says "session ES-n isn't running; run endless session resume ...". To check: whether Claude Code queues input sent to a session that is mid-turn.
- **Guide.** The post-land guide gets rewritten for any project, not Endless's own setup.

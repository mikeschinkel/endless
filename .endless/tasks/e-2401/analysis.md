The registry's existing kinds (opt-in, duration, integer, choice) cannot describe a free-form string, so the five tmux keys need a kind before they can be registered. One generic text kind would only let `settings list` say "a value"; kinds per shape let it say what each key takes and let a malformed value be refused by shape. Ownership and permission checks stay in `Resolve` because they depend on the machine at use time, not on the value's shape; sharing the shape checks between the registry and `Resolve` keeps them from diverging.

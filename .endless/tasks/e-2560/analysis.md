Background check, proposed by Mike. A sidecar JSON file holds the byte offsets of corrections per segment file. A background job skips any segment whose modification time has not changed, and otherwise checks only that segment's last correction: any edit that changes a length before it shifts that offset, so one check covers all earlier corrections without reading the whole file. The sidecar can be rebuilt by scanning the segments. This misses same-length replacements, changes after a segment's last correction and segments with no corrections; the ledger's tamper detection covers those.

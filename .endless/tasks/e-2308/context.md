Mike's rule: all paths the CLI prints should use ~ instead of the full $HOME path. Python already does this through endless.config.tilde(). The Go side prints absolute paths, e.g. `endless-go settings migrate` and the opt-in refusal (config.OptInError) added in E-2284. go-dt, already a dependency, provides FilepathToTilde, DirPathToTilde and ToTilde with a TildeOption (tilde.go). Applies only to text shown to a person, not to paths written into files, JSON output or arguments passed to other programs.

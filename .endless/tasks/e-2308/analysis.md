## Answers from Mike that shape this plan

- **Where `$HOME` becomes `~` (Q1 = both).** Known path values are converted where they are printed or stored, with go-dt's `DirPathToTilde` / `FilepathToTilde` / `EntryPathToTilde` and `OrFullPath`. Paths that are already inside text — `os` errors such as `open $HOME/x: no such file`, doterr `meta: filepath=...`, stored summaries — get a free-text rewrite where the text is output. go-dt converts a typed value; it cannot find a path inside text, so both parts are needed.
- **Where the free-text rewrite lives (Q2).** Not in go-dt: a free-text function is not an obvious enough API for a shared library. Not a new package: Mike wants to avoid package proliferation. It lives in `internal/refusal`, which already owns the stderr output point and the person/agent audience.
- **The free-text pattern.** Replace `$HOME/` with `~/`. Mike's point: in free text a false match is cosmetic, not an execution risk, so a plain search-and-replace is enough. The trailing `/` is itself the segment boundary, so `/Users/mike/` never matches `/Users/mikey/`. `$HOME` with no slash after it (`cwd=/Users/mike` at the end of a line, `(in /Users/mike)`) is replaced too when it is bounded: preceded by start of text, whitespace, `=`, `:`, a quote or an opening bracket, and followed by end of text, whitespace, a quote, `,`, `;`, `:`, a closing bracket, or a `.` that is itself followed by end of text or whitespace (so `/Users/mike.old` is not touched).
- **Agents (Q3 = B).** The rule is about what a person sees; agents keep absolute paths. An agent reusing a path in a tool that needs it absolute (Claude Code's Read/Edit, a quoted shell argument) would otherwise spend output tokens expanding `~`, or fail and retry. So every conversion asks the audience first, using `refusal`'s existing audience detection.
- **Storage (answer 1).** A value known to be a path is stored in `~` form: fault `Fields` values and path arguments a producer formats into a fault's `Summary` / `Detail`. Free text stays as stored and is rewritten only when shown. Because agents keep absolute paths, display for an agent expands a stored `~/` back to `$HOME/`. Changing stored text changes fault fingerprints (computed from the summary); no existing error records matter, so that is accepted.
- **Cwd-relative display (Q4 = B).** The two `displayPath` helpers' cwd-relative form is dropped: the same file should print the same way wherever the command ran.
- **Regression guard (Q5 = B + C).** A static analyzer, plus a test that runs commands under a fake `HOME`. Mike wants every path in a go-dt type, so a path that is not one is itself the defect: the analyzer's second rule flags the stdlib calls go-dt replaces, which is where a plain-string path starts. The fake-`HOME` test catches whatever reaches output regardless of type, for the commands it runs.
- **Existing plain-string path code (Q6 = B).** A baseline file lists the existing sites the second rule would flag; it may only shrink. Converting them is follow-up work per package, not this task.

## Facts from the survey

- Nothing in endless calls `dt.EnsureUserHomeDir` or any go-dt `*ToTilde` yet; `dt.GetUserHomeDir` panics unless `EnsureUserHomeDir` ran.
- Hand-rolled home-to-`~` helpers: `tildePath` in internal/hookcmd, `displayPath` in internal/monitor (reap_worktrees) and in internal/verifycmd. `homeRelative` in internal/monitor is the STORED form of `projects.path` (ED-1562), not a display helper, and is out of scope.
- `refusal.(*Error).Render` returns `humanText` for a person and `Verdict` (plus body) for an agent; `Print`, `Exit` and `Block` go through it.
- `endless errors list/show` is rendered in Go by internal/errorscmd; Python only shells out to it. The live-view fault row (internal/faultrow) also shows stored summaries.
- No lint runs today: no golangci config, no analyzer, no lint recipe in the justfile. `golang.org/x/tools` is already an indirect dependency.
- `endless-go verify` prints `--report-dir`, which `verify_cmd.py` captures and uses as a path. `sandboxcmd`'s seed/reset print the sandbox directory, which E-1608's frozen verify suite asserts is exactly the absolute path.
- Python's `endless.config.tilde()` matches `str(Path.home())` as a bare prefix, so a home of `/Users/mike` also matches `/Users/mikey`.

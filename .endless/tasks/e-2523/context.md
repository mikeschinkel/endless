Endless's go.mod points at sibling go-pkgs checkouts (go-cfgstore, go-cliutil, go-dt, go-logutil and others) through replace directives. Go ignores a dependency's replace lines, so this go.mod builds only on a machine with those checkouts beside it. Those packages are being released in dependency order; once they are tagged, Endless should require the tags and keep no replace. One leftover replace names go-gitutil, which Endless neither requires nor imports, and resolves only from inside a task worktree.

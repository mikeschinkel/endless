Every `session monitor` pane recomputes every 2 seconds whether or not anyone can see it: a database query, `git status` for every row with a worktree, extra git checks on the focused worktree, a tmux resize, and a job-runner trigger. Mike can see only one session's monitor at a time (plus an optional `project monitor` in a second terminal), so nearly all of that work is wasted. `task spawn` starts a `session monitor` in every window, so pane count grows with work in flight.

Find the sites with: git grep -l '"github.com/mikeschinkel/go-doterr"' -- '*.go'. For each package in that list, copy go-doterr's doterr.go into the package (renaming its package clause), drop the import, and remove the 'doterr.' qualifier from calls. go-doterr's cmd/sync-doterr can keep the copies in sync. Watch for errors crossing packages: each embedded copy has its own identity and doterr detects mixing between copies, so code that reads metadata from another package's errors (internal/faults is the likely place) needs checking with tests, not just a build. Finish with go mod tidy, then confirm no go.mod mentions go-doterr and GOWORK=off go build ./... and the tests pass.

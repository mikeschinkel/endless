go-doterr is a drop-in: its README says to copy doterr.go into each package that uses it, so the functions join that package's namespace and no module dependency exists. Since the layered config package was added, Endless instead imports github.com/mikeschinkel/go-doterr in about 30 Go files (internal/config, internal/faults, internal/jobs, internal/settings and others) and go.mod carries a require plus a replace pointing at a sibling checkout. That replace keeps Endless's go.mod from building anywhere but this machine, and go-doterr is not meant to be versioned as a dependency at all. go-doterr's doterr.go must not be changed by this work.

Liveness (observeTmuxServers) scans every socket in the tmux socket directory on every monitor tick. On 2026-10-12 that directory held 153 sockets, 151 of them dead: 135 leaked by internal/sessionmonitorcmd/tag_test.go (one per Go test run), the rest by verify suites and probes whose private servers were killed without unlinking. Each dead socket cost two tmux execs per tick per monitor, about 1s of child CPU per tick. The parent task adds a connect() precheck so a dead socket no longer forks, and stops tag_test.go leaking, but dead files still accumulate and are still scanned. Open question for planning: the directory is shared with non-Endless tmux servers, so whether Endless may unlink a socket it did not create (refused connect = no server) is a product decision; alternatives are cleaning only Endless-named sockets, or only sockets created by Endless's own test/verify harness.

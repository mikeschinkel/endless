On macOS, Windows cannot run in a container; it needs a VM. Options raised: UTM (open source; on Apple Silicon it runs Windows 11 for ARM natively, x86 Windows only through slow emulation); VMware Fusion (reportedly free since Broadcom's 2024 licensing change, not open source; whether that still holds is to be checked); Parallels is ruled out (not open source, too expensive). Tart (tart.run) runs only Linux and macOS guests. Mike also has an ESXi 7.x server (https://esxi.home) and a Proxmox server (https://proxmox.home), which can run x86 Windows VMs reachable from the Mac over the network, and GitHub Actions offers hosted Windows machines with nothing to run locally. Questions include x86 versus ARM Windows (Go tests are mostly architecture-neutral, but CI and users are x86), Windows licensing for a test VM, and how an agent drives a remote Windows VM (SSH, WinRM).

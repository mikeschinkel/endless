The guide is capped at seven or fewer top-level sections, and sections are getting long. The user accepts subsections stored as files in a subdirectory that has the same base name as the section's markdown file, addressed by relative path without the .md extension, e.g. endless guide tasks/post-land. Today the guide command resolves only a flat docs/guide/<section>.md (src/endless/cli.py, guide_dir.glob('*.md')), and docs/guide/help/ already holds per-command help files, so a subdirectory must count as a subsection only when a sibling <name>.md section exists. The guide index and its regenerator (guide_map.py, just guide-index, the regenerate-guide skill) must learn subsections too.

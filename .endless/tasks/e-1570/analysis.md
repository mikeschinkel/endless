(1) endless task spawn --attach <id>: opens NEW tmux window via tmux new-window + send-keys 'claude attach <short-id>'. Used when a bg agent needs dedicated focus separate from the coordinator's pane. (2) endless task attach <id>: execs current pane via os.execvp('claude', ['attach', short_id]). Used from a fresh shell to drop into a running bg agent. Both leverage claude attach (Claude's bg→fg view mechanism). Detaching leaves the bg agent running.

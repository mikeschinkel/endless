A task's steward (ED-1605) is the session whose board keeps a task in view so the user remembers to work on it and spawn it. Stewardship is calculated every time a board is drawn, and never stored. The steward is the present session that filed the task; failing that, the only present session that edited it. The task's claiming session is not counted, and two candidates on the deciding rung leave the task ambiguous, with no steward.

Today the only way to see a task's steward is to open boards and look, and the only way to change it is per board: `session hide --task` takes a task off one session's board, and `session unhide --task` pins it on another. The user often needs to know which session is stewarding a given task, and to go to that session. Reading through `task show` for it is too slow. There is also no single command that says "this session should steward that task".

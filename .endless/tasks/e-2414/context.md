A task's steward (ED-1605) is the session whose board keeps a task in view so the user remembers to work on it and spawn it. Today stewardship is worked out every time a board is drawn and never stored. The steward is the present session that filed the task; failing that, the only present session that edited it. The task's claiming session is not counted, a session that hid the task is not counted, and two candidates at the deciding step leave the task ambiguous, with no steward.

Today the only way to see a task's steward is to open boards and look. The only way to change it is per board: `session hide --task` takes a task off one session's board, and `session unhide --task` on a task that is not hidden writes a pin (E-2293) that keeps the task on that board as well. A pin does not make the session the steward. The user often needs to know which session is stewarding a given task, and to go to that session, and has no single command that says "this session should steward that task".

ED-1633 retires pins: touch is the user's command for putting a task on a session's board, a touched task is never suppressed by another session's stewardship, and a touch does not make the session the steward.

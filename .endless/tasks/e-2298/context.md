tmux-continuum counts every tmux process on the machine; if another server exists when its plugin loads it installs no auto-save, and when the server has just started it skips auto-restore. The Endless console runs a second server (tmux -L endless, started by endless project monitor --tmux), so every task server started while the console is up never saves or restores. Observed 2026-10-10/11: after two tmux deaths no restore happened, and no resurrect save was written after 22:23 on 2026-10-10 although continuum is set to save every 5 minutes. Stray private test servers left by agents add to the count too. Options include not running the console as a separate tmux server, or having the planned endless start take over continuum's save and restore. PRODUCT: affects every Endless user who uses tmux-continuum.

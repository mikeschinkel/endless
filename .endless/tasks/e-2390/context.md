Slugs are user-facing in commands, and code assumes one project per slug. Slugs are derived from a project directory's last segment, so two directories with the same final name collide; today the second must be registered by hand with --name. Even as projects move to GUIDs for identity, slug uniqueness should be an enforced invariant. The derivation rule needs a defined behavior on collision (pick a distinct slug or require --name), and every place that maps a directory to a slug by its last segment must go through that rule.

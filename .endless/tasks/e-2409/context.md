Planning the hook event argument on 2026-10-19, Mike proposed a watchdog that periodically looks for misconfigurations the user can resolve and raises faults for them. The motivating case: a Claude Code hook entry that wraps or pipes endless-go hook claude, which today is found only when a payload fails to parse, or when endless setup claude-hook is run. Built on doctor's check registry rather than beside it, so a check and its remedy are written once. Endless already schedules jobs (main sync, triage, auto-spawn). A check that sometimes fails on its own would raise faults on a schedule, so only dependable checks belong in the job.

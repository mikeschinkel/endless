E-2335 found that .endless/hooks scripts (post-land, post-worktree-create, seed-sandbox, pre-land), tasks verify.sh, _harness.sh, config.json and verbs.jsonl are tracked, and mainsyncjob fast-forwards main from origin with no inspection when only origin moved. A cloud session that pushes to main therefore gets scripts executed on the user's machine at the next land, worktree create or verify. Probing showed cloud sessions push unprompted (Anthropic's cloud Stop hook re-prompts them to commit and push), and that a committed cloud guard is bypassed by a session that clones the repo mid-session. This inspection is the backstop. Ledger lines arriving by git are also never validated.

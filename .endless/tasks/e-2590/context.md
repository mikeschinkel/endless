E-2589 holds back faults for failures that usually pass on their own: a source marks a failure transient, and it becomes a fault only when it keeps recurring. Which failures count as transient is decided by hand-written lists — main-sync's `unreachablePhrases` in `internal/mainsyncjob`, and the error types E-2589 names for the stopfailure hook. Those lists are guesses. On 2026-11-04 GitHub answered `Permission denied (publickey)` during its own incident, a message the hand-written list treats as a real authentication failure.

E-2589 also records each closed run of transient failures: its fingerprint, its occurrence count, and how long it took to clear, or that it became a fault. That history is the evidence this research needs, so it cannot start until E-2589 has landed and some months of runs have accumulated.

endless's go.mod replaces go-cfgstore with the local checkout at ../go-pkgs/go-cfgstore. go-cfgstore now requires go 1.27.0, because Go 1.27 ships encoding/json/v2 and refuses it in modules that declare an older go line. A main module whose go line is below a dependency's stops with 'go: updates to go.mod needed; to update it: go mod tidy'. endless declares go 1.26.2, so it stops building once go-cfgstore's Go 1.27 change lands on main. Confirmed by building endless with a scratch -modfile that points the replace at go-cfgstore's task branch.

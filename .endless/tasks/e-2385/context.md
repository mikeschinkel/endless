E-2240 added `endless start`, which runs Endless's own tmux servers (`endless-console` and `endless-tasks` in its configured socket directory). Its plan let spawns fall back to "behave as today" when `endless-tasks` is not running, so a spawn, a claim's window or an auto-spawn still opens on whatever tmux server the caller is in, usually the user's default server. Mike, 2026-10-17: that was never intended; Endless supports only the tmux servers it controls, and it should never fall back to the default. Tmux is an enabling technology for Endless, not part of its foundation; other multiplexers, or one of Endless's own, may follow.

Mike also asked for `endless stop` to pair with `endless start` and wind the servers down gracefully, one at a time or all together, and reported that `endless start` restores task windows in the wrong order. When `endless start` cannot detect a terminal, it prints attach commands; Mike asked that it open the platform's default terminal instead where there is one.

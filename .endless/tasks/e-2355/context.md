Prompted by wanting to fix a tmux crash (the copy-mode grid_free_line abort) as an upstream PR by cloning tmux and adding it as an Endless project. Today managing a repo with Endless adds things to it: a .endless/ directory (config, ledger JSONL, task directories, worktrees under .endless/worktrees), a CLAUDE.md pointing at endless guide, gitignore entries, Claude hooks, and frequent commits such as 'Endless: record ledger entry' on the default branch (go-cfgstore's main is 62 commits ahead of origin, many of them ledger entries). Upstream maintainers who do not use Endless would see all of that as noise or would reject it, so a contribution branch must be free of it. PRODUCT: any Endless user contributing to third-party open source hits this.

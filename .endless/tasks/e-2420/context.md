A task can only be continued from its earlier session through session goto --resume, which needs that session's Claude transcript in Claude's projects directory. Claude Code deletes transcripts older than its cleanupPeriodDays setting, 30 days by default. Once a transcript is gone, resume refuses and the only route left is --new-transcript, which starts the task over without its earlier context. E-2418 makes claim, bind, spawn and prime all route to resume, so a deleted transcript blocks every way of continuing a task. The user wants cleanupPeriodDays set to 3650 by default, or to a value the user gives in the Endless config; Endless exists to enhance Claude, so changing a documented Claude Code setting is in scope. E-2416's captured transcripts could also restore one, for projects that opt in; keeping them in Claude's directory is decoupled from that so it holds for everyone.

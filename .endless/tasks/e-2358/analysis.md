_live_sessions in session_cmd.py passes the cwd's --project-root to session-query list-live, so a session whose project is not the cwd's is never live from there. Ids are global, and task show already ignores the cwd's project, so a lookup by id has no reason to be scoped. Listings with no id (session list) keep the cwd default. If some command does need scoping, it should search the whole DB on a miss and name the --project flag it needs.

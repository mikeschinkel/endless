Mike's expected design: each new line carries a hash of the prior line. Open point: checking only the last two lines proves just the last link, so an edit further back goes undetected, because the prior line is unchanged and its hash still matches. A full check has to walk the file. One way to avoid doing that every time: record each segment's size, modification time and whole-file hash, and re-read a segment only when its size or time changed. A segment past its rotation limit should never change, so any change to one is itself suspect.

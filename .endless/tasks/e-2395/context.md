Mike, 2026-10-18, while planning E-2300: he is standardizing planning so that deterministic processes can be built around plans. A task's plan has two parts, plan items (what will be true) and approach prose (where and how). E-2300's prose was divided into numbered sections that no template asked for; Mike asked what they were. They are sections: each groups the approach prose for one area of change, roughly one commit, ordered loosely by dependency, with Tests last by habit. Sections exist today only as freeform Markdown headings, so nothing can recognise, count or check them.

Out of scope: linking sections to plan items (for example, a section naming the items it serves). Mike: that might be useful only if it were possible in all cases, and it is not the subject here.

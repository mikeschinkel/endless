Filing a brainstorm with --justification (task add --type brainstorm --justification ... --db main) created the task and wrote its context, then failed: 'ValueError: no document mirror for content justification'. task_cmd.add_item calls _mirror_task_doc(item_id, "justification", ...), which calls doc_mirror.kind_for("justification"); doc_mirror has no kind for justification, so it raises. task_cmd's update path makes the same _mirror_task_doc call for justification, so task update --justification likely fails the same way. The justification was in add_item's creation payload, but nothing confirmed whether it was stored, since task show prints none. The field became typed task content in E-1562's commit 1dbbb7ffd.

Consolidated into E-1940 per ED-1550 (3): several symptoms of one cause are one task. E-1308, the unsettled probe's false verdicts, and the reaper's refusal to reap landed worktrees are all the same defect — no reliable landed-state determination, so each surface invents its own git probe and all of them break on rebase-landed branches. E-1940 now owns the cause and carries E-1308's use-case verbatim in its analysis: report 'already landed (commit <sha>); nothing to do' when the worktree is gone, falling back to today's error only when the work is genuinely unaccounted for. Note for whoever implements it: E-1308's proposed 'git branch --merged main' probe does NOT work, because land rebases and a landed branch is therefore not an ancestor of main; the recorded task_landings row is the reliable signal.

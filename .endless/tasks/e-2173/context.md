The workaround in use is to change a field that does not need changing, most often phase, purely for the touch side effect: 'I set to now but only because updating a task is how I add a task to session status.'

That writes a real field change into the ledger to buy a display effect, so the task's recorded phase stops meaning what it says, and a later reader cannot tell a deliberate re-prioritization from a side-channel.

It also fires a change notice to every other session holding the task.

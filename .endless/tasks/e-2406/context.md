Registration scaffolds the output style and never activates it (src/endless/register.py _scaffold_output_style, E-1919), so every newly registered project raises WARN-0021 "the Endless output style is installed but not active" (internal/outputstylecmd warnInert). Its remedy says "re-run this command with --activate", which names nothing when the command was a registration, and suggests /config output-style=endless, which needs a Claude session in that project. Endless can activate it without one: endless setup output-style --project <name> --activate writes outputStyle into <project>/.claude/settings.json.

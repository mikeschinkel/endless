Corrects this task's first diagnosis, which blamed the order of writes inside project init. go-filesys's reflog shows what happened: project init ran at 16:10 and made two commits, 'Endless: shipped_file.written .endless/tasks/CLAUDE.md' and then 'Endless: bring project up to Endless usage', which is the first commit holding lefthook.yml. At 16:21 a git pull --rebase replayed both onto GitHub's 'Initial commit'. git runs prepare-commit-msg for each replayed commit. While it replays the first one, the working tree is the remote's commit plus that commit's changes, so the tracked lefthook.yml is absent, but the hooks are installed and the untracked lefthook-local.yml (which holds the endless commands) is present. lefthook ran the endless-task-trailer command from lefthook-local.yml, but its hook sync step needs lefthook.yml and printed 'sync hooks: Skipping hook sync: could not create a checksum file: unable to get config update timestamp: no lefthook config found'. Reproduced in a scratch repo: during a rebase, the hook sees no lefthook.yml for the first commit and sees it for the second.

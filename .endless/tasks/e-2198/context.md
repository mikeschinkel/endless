The column answers 'is there work product here, and where is it?' — outstanding, none, all landed, or not yet determined. unsettledMark picks the not-started glyph from one test on the row's own status, and an epic's status is derived from its children while its own branch stays empty, so every epic fails that test permanently. Measured on E-1991: five children have landed code, three terminal, and the row still renders the not-started mark. The label is not the defect — an epic in this state has plenty of work product, so 'no work' would be as false as 'not started'. The separate mis-signal on a todo that landed mid-flight and kept working is deliberately out of scope and has its own task; it needs a source of truth that does not exist, since the unlanded cache cannot distinguish 'never had work' from 'landed all of it'. E-2107 set the no-probe-on-the-hot-path constraint this fix must respect.

Agent-authored durable content keeps carrying the session that produced it -- 'This session did exactly that', 'Found while auditing X during E-1834', titles that narrate a problem rather than state the work (E-1870 shipped as 'Guide never tells an agent...', which passed the title-verb gate only because 'Guide' collided with the allowlist as a noun).

The artifacts are read later by people and sessions with no memory of the authoring session, so narration is noise at best and misleading at worst, while genuine provenance still has value and should not be blanket-banned.

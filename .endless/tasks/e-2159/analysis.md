One helper per language whose constructors name the class — no_report, report, report_if, fault, relay, warn, info — rendering today's text for humans and, for an agent, E-2097's verdict line carrying the directive at both ends.

A build check fails on any refusal construction, stderr write or non-zero exit that skips the helper: in Go, any os.Stderr reference outside the package; in Python, an AST walk of src/endless.

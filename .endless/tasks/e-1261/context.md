Currently sessions use `E-NNN` IDs which collide visually with task `E-NNN` IDs in display (e.g. `endless session show` returns "Session E-359" but E-359 might also be a task in the same project).

The E-1031 plan anticipates a two-letter convention: `ES-NNN` for session, `EF-NNN` for focus, `ET-NNN` for task.

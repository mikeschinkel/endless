E-1993's plan gate (_require_spawnable in src/endless/task_cmd.py) refuses to claim an unplanned task, because a claim starts work and work runs from a plan. A session still working out a task's plan with Mike needs to own the task before then, for its session_tasks associations. task bind already does that: it records ownership without changing status, creating a worktree or passing the gate, and a later claim from the same session goes through the gate and moves the task to underway, the same path primed sessions take. But the refusal offers only writing a plan or task prime, never bind, so a session in this situation (the gomion session, from E-2283) concluded the gate had to be loosened. The bind line belongs in the claim refusal only. Spawn hands the task to a new session, which has nobody to plan with.

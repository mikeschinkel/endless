Mechanism chosen by Mike, 2026-10-29: a commit-msg Git hook that Endless installs per repo. It reads the task from the branch name (task/NNNN) and appends the Endless-Task trailer, so it covers every commit from any tool (plain git commit, GoLand, agents); worktrees share the repo's hooks. Rejected: an endless git passthrough (applies only when someone remembers to use it, and never to GoLand commits) and rewriting commands in Endless's Claude Bash hooks (agent sessions only, and rewriting a command is more fragile than appending to a message). Known gap: git commit --no-verify skips the hook.

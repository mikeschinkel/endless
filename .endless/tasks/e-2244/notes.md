## Justification

Cross-project links between endless and go-cfgstore already exist, and a public project linking to a private one must not leak the private side. Starting points: GitHub cross-repository references from private repos, Jira restricted issue links, git-bug, Radicle collaborative objects, Fossil tickets, Matrix history_visibility, Bell-LaPadula and lattice-based information flow, Copybara and ShipIt history scrubbing.
